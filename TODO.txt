3. v1.0.2 - Add PUT /tasks/{id}
-------------------------------

Urgency:
After POST works.

File:
src/main/java/com/mab/tasktracker/server/TaskHandler.java

Imports:
- java.io.InputStream
- java.util.Optional
- com.mab.tasktracker.domain.Task

Behavior:
- Add manual parsing for /tasks/{id}.
- Handle PUT /tasks/{id}.
- Treat PUT as "replace/update this task's editable fields."
- For now, read the request body as the replacement task title.
- Call taskService.renameTask(id, newTitle).
- If ID exists, return HTTP 200 and formatted updated task.
- If ID does not exist, return HTTP 404.
- If title is invalid, return HTTP 400.
- Keep GET /tasks behavior unchanged.

Important:
- com.sun.net.httpserver.HttpServer does not understand {id} path variables.
- You must parse exchange.getRequestURI().getPath() manually.

Manual curl test:
curl -i -X PUT http://localhost:8080/tasks/{id} --data "Replacement title"

Postman test:
- Method: PUT
- URL: http://localhost:8080/tasks/{id}
- Body: raw text
- Text: Replacement title

Expected:
- Existing ID: 200
- Missing ID: 404


4. v1.0.3 - Add PATCH /tasks/{id}
---------------------------------

Urgency:
After PUT works.

File:
src/main/java/com/mab/tasktracker/server/TaskHandler.java

Imports:
- java.io.InputStream
- java.util.Optional
- com.mab.tasktracker.domain.Task

Behavior:
- Handle PATCH /tasks/{id}/title.
- Read new title from plain text request body.
- Call taskService.renameTask(id, newTitle).
- Return HTTP 200 and formatted task if renamed.
- Return HTTP 404 if task is missing.
- Return HTTP 400 if title is invalid.
- Handle PATCH /tasks/{id}/complete.
- Handle PATCH /tasks/{id}/reopen.
- Complete route calls taskService.completeTask(id).
- Reopen route calls taskService.reopenTask(id).

Manual curl tests:

- curl -i -X PATCH http://localhost:8080/tasks/{id}/complete
