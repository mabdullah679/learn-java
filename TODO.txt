4. Add HTTP server by hand
--------------------------

Goal:
Expose the task tracker as a backend API without Spring Boot.

Likely file:
src/main/java/com/mab/tasktracker/server/TaskHttpServer.java

Possible Java API:
- com.sun.net.httpserver.HttpServer

Behavior:
- Start server on a local port.
- Route API requests to TaskService.

Initial routes:
- GET /api/tasks
  - return all tasks

- POST /api/tasks
  - create task from request body
  - return created task

- GET /api/tasks/{id}
  - return task if found
  - return 404 if missing

- PATCH /api/tasks/{id}/title
  - rename task
  - return updated task if found
  - return 404 if missing

- PATCH /api/tasks/{id}/complete
  - complete task
  - return updated task if found
  - return 404 if missing

- PATCH /api/tasks/{id}/reopen
  - mark task incomplete
  - return updated task if found
  - return 404 if missing

- DELETE /api/tasks/{id}
  - delete task
  - return success if deleted
  - return 404 if missing

Imports:
- HttpServer
- HttpExchange
- InetSocketAddress
- IOException
- StandardCharsets
- TaskService
- Task
- List
- Optional

Tests:
- Add later after service is complete.
- Could begin with manual curl tests before automated HTTP tests.
