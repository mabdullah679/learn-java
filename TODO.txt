Task Tracker App TODO
=====================

Current completed milestone:
v1.0.3

Completed:
- Domain model implemented and tested.
- Repository implemented and tested.
- Service layer implemented and tested.
- Entry point starts the HTTP server.
- /tasks route is wired to TaskHandler.
- GET /tasks works with readable plain-text output.
- Wrong path returns 404.
- Wrong method on /tasks returns 405.
- Maven builds a runnable jar.
- Dockerfile runs the jar in a container.
- Docker deployment was tested.
- Postman testing was completed for the current API.
- POST /tasks creates tasks from plain-text request bodies.
- POST /tasks returns 201 with the created task.
- POST /tasks returns 400 for invalid titles.
- PUT /tasks/{id} updates an existing task title.
- PUT /tasks/{id} returns 200 with the updated task.
- PUT /tasks/{id} returns 404 for missing task IDs.
- PUT /tasks/{id} returns 400 for invalid replacement titles.
- PATCH /tasks/{id}/title updates an existing task title.
- PATCH /tasks/{id}/complete marks an existing task completed.
- PATCH /tasks/{id}/reopen marks an existing task incomplete.
- PATCH /tasks/{id} routes return 404 for missing task IDs.
- PATCH /tasks/{id}/title returns 400 for invalid replacement titles.

Current verification commands:
- mvn test

- java -jar target/task-list-app-1.0-SNAPSHOT.jar
- docker build -t task-tracker:1.0.3 .
