4. Add POST /tasks
------------------

Urgency:
After GET response is readable.

File:
src/main/java/com/mab/tasktracker/server/TaskHandler.java

Imports:
- java.io.InputStream
- java.nio.charset.StandardCharsets
- com.mab.tasktracker.domain.Task

Behavior:
- Handle POST /tasks.
- Read request body as a title string.
- Call taskService.createTask(title).
- Return created task.
- Return HTTP 201 on success.
- Return HTTP 400 if title is invalid.

Implementation notes:
- Keep request parsing simple at first.
- Body can be plain text before JSON exists.

Manual test:

Expected:
- HTTP 201.
- Response includes created task title.

7. Add PATCH Routes
-------------------

Routes:

- PATCH /tasks/{id}/complete
